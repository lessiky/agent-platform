### 1.3 审核门禁与调用链接入

- `CallTool` 门禁：工具 `requires_approval=true` 时不直接执行，生成审核请求返回 `CallToolOutcome{PendingApproval}`；各调用来源按自身语义处理（HTTP 202 / 日志挂起）。
- 对话/外部调用挂起 (2026-08-24 修复)：`runToolRounds` 工具轮遇到需审核工具时**立即暂停本轮** — 同批后续工具调用不再执行、不再发起后续模型轮，原对话轮以等待审核结束 (执行任务转 `waiting_approval`)；审核决策后 `ContinueAfterApproval` 回灌执行结果续答，续答通知明确"上一轮在该工具处暂停、其后步骤未执行"，避免模型在续答时重复执行已执行/未执行步骤。
- 调用来源 (source)：
  - `manual`：MCP 详情页手动调用工具 → HTTP 202 (approval_id + approval)
  - `runtime`：Agent 运行时模拟流量 → agent_logs 记 `waiting_approval`，调用结果带 `pending_approvals`
  - `api_invoke`：API Key 外部调用 `/invoke` → HTTP 202
  - `workflow`：M5 预留
- 审核通过后经 `ExecuteTool` (绕过门禁) 执行，成功回填 result + executed_at；**执行失败仅回填 `{"error": ...}`，不回滚审核状态**（审核决定不被执行失败推翻）。
- 删除 MCP 服务器时级联删除其审核请求。
- 工具发现 (健康检查刷新) 对 `requires_approval` 做合并保留，服务端刷新不会把开关刷回 false。

### 1.4 审核生命周期状态机

```
                          ┌─ approve (mcp:approve 权限) ─► approved: 执行工具并回填 result
pending ─────────────────┤
   │                     ├─ reject (mcp:approve 权限)  ─► rejected (带审核意见, 不执行)
   └─ 超时扫描 (30s) ────┴─► expired (按 on_timeout 策略处理)
            ├─ on_timeout=reject  : 终止, 不执行
            └─ on_timeout=approve : 自动通过并执行, 回填 result
```

- 并发安全：`MarkDecided` 用 `UPDATE ... WHERE status='pending'` 乐观锁；人工已处理时超时处理自动跳过，保证恰好一次决策。
- 超时扫描：`ApprovalTimeoutChecker` 每 `ApprovalTimeoutScanInterval` (30s) 执行 `ProcessExpired`，超时由系统写审计日志 (comment 含策略说明)。

### 1.5 权限与审计

- 新权限 `mcp:approve`（通过/驳回审核请求）；`mcp:read` / `mcp:write` 控制查看与配置。
- 种子：`database/seed.go` 幂等初始化 7 权限 / admin、operator 两角色 / demo_user=admin；admin 登录时自动追加 `mcp:approve`。
- 审计动作 6 类（全部落 `audit_logs`）：
  `mcp.approval.created` (系统) / `mcp.approval.approved` (审核人) / `mcp.approval.rejected` (审核人) / `mcp.approval.expired` (系统, 含 auto_approve 标记) / `mcp.approval_settings.update` (操作人) / `mcp.tool_approval.update` (工具开关变更)。
- 审计写入失败仅告警，不阻塞主流程。

## 5. 运行方式

无新增 `.env` 配置：超时扫描间隔固定 30s，随主进程启停；权限与角色由启动时幂等种子初始化。

示例：

```
# 工具级审核开关 (MCP 详情页 Switch 即调此接口)
curl -X PUT localhost:8080/api/v1/mcp-servers/$MCP_ID/tools -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '{"tools":[{"name":"ticket.create","requires_approval":true}]}'

# 触发需审核调用 (manual 来源, 返回 202)
curl -X POST localhost:8080/api/v1/mcp-servers/$MCP_ID/tools/call -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '{"name":"ticket.create","arguments":{"title":"t"}}'

# 审核列表 / 配置 / 通过 / 驳回
curl localhost:8080/api/v1/approvals?status=pending -H "Authorization: Bearer $TOKEN"
curl localhost:8080/api/v1/approvals/settings -H "Authorization: Bearer $TOKEN"
curl -X POST localhost:8080/api/v1/approvals/$ID/approve -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '{"comment":"同意"}'
curl -X POST localhost:8080/api/v1/approvals/$ID/reject -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '{"comment":"参数缺失"}'
```
