### 1.3 绑定作用域扩展（核心语义）

```
绑定顶级分类 C（读写或只读）
   │
   ├─ 读路径: BoundCategoryIDs(C) = {C} ∪ children(C)   （运行时单点扩展, 绑定表不建子级行）
   │     ├─ 对话注入 (runTurn / ContinueAfterApproval 双组装点)
   │     ├─ search_knowledge 工具
   │     └─ Agent 试算 GET /agents/:id/kb/search
   ├─ 写路径（一键总结入库）: 目标分类 ∈ 读写作用域（含扩展）; 只读分类（含其子级）→ 403
   └─ 平台试算 GET /kb/search: 不扩展（调用方显式分类集 = 平台视角预览）
```

### 1.4 只读绑定（API 向后兼容）

- Agent 创建/更新请求新增**可选** `knowledge_categories_readonly: string[]`; 不传 = 全部读写（存量客户端零改动）
- 读写 / 只读两数组交集非空 → 400（同一分类不可双重身份）
- 只读与父子扩展正交: 只读绑顶级 → 检索命中父 + 子, 写入父 + 子均 403
- 审计: `kb.agent_bound` / `kb.agent_unbound` detail 含 `read_only`; rw↔ro 标志变更记录 `old_read_only`
